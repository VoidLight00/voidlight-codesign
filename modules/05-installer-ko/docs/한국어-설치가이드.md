# VoidLight CoDesign 한국어 설치 가이드

이 문서는 `v0.1.4-ko-alpha` 테스터가 설치부터 첫 실행까지 진행하기 위한 안내다. 알파 빌드는 개발자 프리뷰이며 macOS 서명 및 공증이 완료되지 않았을 수 있다.

## 시작 전 확인

- macOS 13 이상 권장
- 테스트용 작업 환경 권장
- provider 연결 방식 준비
  - 권장: official API key
  - 선택: VibeProxy/CLIProxyAPI experimental 경로
- 상업적·대규모 사용 전 provider 약관 확인

## 설치 방법 A: Homebrew Cask PoC

```bash
brew install --cask voidlight/tap/voidlight-codesign
```

> 현재 Cask는 배포 흐름 검증용 PoC다. 실제 GitHub Release의 DMG asset 업로드와 SHA256 고정 전까지는 운영 배포용이 아니라 설치 동선 점검용으로만 사용한다.

## 설치 방법 B: 수동 설치

1. 릴리스 페이지에서 macOS 빌드를 내려받는다.
2. 압축 파일 또는 DMG를 연다.
3. `VoidLight CoDesign.app`을 `Applications` 폴더로 이동한다.
4. 첫 실행 전에 릴리스 노트의 서명/공증 상태를 확인한다.

## unsigned alpha 실행 안내

알파 빌드가 unsigned 상태라면 macOS Gatekeeper 경고가 표시될 수 있다.

- 가능한 경우: `시스템 설정 → 개인정보 보호 및 보안`에서 차단된 앱 실행을 직접 허용한다.
- 격리 속성 해제는 알파 테스트용 최후 수단이며 v1.0 배포 정책이 아니다.

```bash
xattr -dr com.apple.quarantine "/Applications/VoidLight CoDesign.app"
```

## Provider 연결

첫 실행 후 provider 연결 방식을 선택한다.

### 1. official API key 방식 권장

- 공식 provider가 발급한 API key를 사용한다.
- 비용, rate limit, 약관이 명확하다.
- 알파에서도 first-class fallback 경로로 유지한다.

### 2. VibeProxy/CLIProxyAPI 방식

- 별도 앱을 사용자가 직접 설치해야 한다.
- 기본 local proxy는 `127.0.0.1:8317` 계열을 사용하며, 일부 OpenAI-compatible 설정은 `/v1` 경로를 포함한다.
- diagnostics가 `ECONNREFUSED`/`ENOTFOUND`를 감지하면 official API key 경로로 되돌아가도록 안내한다.
- provider ToS 및 계정 정책 리스크가 있어 experimental로 표기한다.
